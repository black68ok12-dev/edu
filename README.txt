국방예산 웹 대시보드

실행
  index.html을 더블클릭하여 브라우저에서 여세요.
  인터넷 연결이나 별도 설치 없이 모든 차트와 필터를 사용할 수 있습니다.

기능
  부문 및 회계구분 필터, 분석 연도 전환, 내부거래·보전지출 포함/제외
  9개 시각화, 프로그램 검색 및 정렬, 필터 결과 CSV 저장
  모든 화면은 엑셀에서 추출한 32개 프로그램 행을 기준으로 합니다.
  부문 비교 및 워터폴은 두 연도를 함께, 나머지 규모 차트는 선택한 연도를 표시합니다.
  원형 차트와 트리맵은 양수 지출만 사용합니다.
  검색은 상세 표와 CSV에만 적용됩니다.

원본 및 데이터 갱신
  원본: 상위 폴더의 프로그램별_재원_2026_2027.xlsx
  웹 데이터는 data.js에 저장되어 있어 파일을 열기만 해도 동작합니다.
  엑셀 수정 후에는 Python(openpyxl 설치 환경)으로 update_data.py를 실행하고
  브라우저를 새로고침하세요. 원본 엑셀을 직접 수정하지는 않습니다.
  현재 환경에서 갱신하는 명령:
  & 'C:/Users/교육생-PC11/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' 'C:/edu2/dashboard/update_data.py'

금액 및 집계
  금액 단위는 억 원입니다. 조 단위 문자열을 숫자로 변환하여 집계합니다.
  증감 = 2027년 - 2026년, 증감률 = 증감 / 2026년.
  프로그램 행의 합산 값은 2026년 677,039억 원, 2027년 732,776억 원입니다.
  원문 총 재원과는 반올림으로 각 연도에 1억 원 차이가 있습니다.
  음수 조정액을 포함할 때 증감률의 분모에도 부호를 그대로 반영합니다.

파일
  index.html : 웹 페이지
  styles.css : 반응형 디자인
  app.js : 차트·필터·검색·정렬·CSV
  data.js : 원본 엑셀에서 추출한 데이터
  update_data.py : 데이터 갱신 도구
